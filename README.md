# cursorpage

浏览器单页工作台（原生 ES 模块，零依赖）。

## 起服务看页面

    python3 -m http.server 8000

浏览器打开 http://127.0.0.1:8000/ ，改样例点运行看结果。

## 测试

    node tests/run.js

## 场景自检

    node check_sample.js

## 游标设计

- 排序：分数降序，同分按编号升序（全局有序，游标可定位）。
- 游标：`分数:编号` 复合键；翻页时在已排序数组里二分定位「严格大于游标键」的起点再切片，不重排、不用偏移量，插入/删除后旧游标仍有效。
- 游标格式损坏抛 `E_BAD_CURSOR`，不会静默回第一页。
